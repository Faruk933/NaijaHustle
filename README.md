# Naija Hustle 🇳🇬

A Nigerian life-simulation game starting in Abuja.

## Vision

Build a life from almost nothing: work, hustle, manage money, build relationships, find housing, travel around Abuja, start businesses, and progress toward wealth and influence.

## Abuja-first map

The world is designed around real Abuja geography. The first map layer will model real districts, roads, major routes, and recognizable landmarks while keeping gameplay locations and fictional businesses under our control.

Initial districts:

- Central Area / CBD
- Wuse 1 & 2
- Garki 1 & 2
- Maitama
- Asokoro
- Jabi
- Utako
- Gwarinpa
- Kubwa
- Lugbe
- Airport Road
- Life Camp
- Karu

## Product direction

- Mobile-first simulation gameplay
- Server-authoritative player economy
- Separate Supabase project from EasyTasksz
- Real-world-inspired Abuja map architecture
- Free-to-play core with non-pay-to-win monetization

## Build phases

1. Foundation and game shell
2. Abuja map and navigation
3. Character creation and player state
4. Money, needs, time, jobs and daily actions
5. Housing, transport, social systems and events
6. Businesses, progression and monetization
7. Multiplayer/social features
8. Polish and mobile optimization
